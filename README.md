# How to Play

## Opening the Game
- Open 'GameEngineX.sln'
- Run the program

## Adjusting List of Names
- Open 'names.txt' in the root folder
- Adjust the contents of 'names.txt' and save 
- Wheel will reflect the changes to the list of names

## Spinning
- Press **'SPACE'** to spin the wheel
- Wheel will spin and display the winner's name after stopping (with fun confetti)
- Press **'ENTER'** to close the popup
